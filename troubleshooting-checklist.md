# Troubleshooting Checklist

1. What changed? (update, new software, password change, new device)
2. Who is affected? (one user, a team, everyone)
3. What's the simplest fix to try first? (restart, reconnect, check cables and settings)
4. Record the symptoms, the steps I tried and the result in the ticket.
5. Explain the fix to the user in plain language.
