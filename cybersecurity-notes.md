# Cyber Security 101 Notes

## CIA triad
- Confidentiality: only authorised people can see the data.
- Integrity: the data stays accurate and unaltered.
- Availability: systems and data are there when people need them.

## Common attacks
- Phishing: a fake message tricks a user into giving up credentials or running malware.
- SQL injection: an attacker sends database commands through an input field. Parameterised queries prevent it.
- Session hijacking: an attacker steals a session token and acts as the user.

## Defences
- Multi-factor authentication (MFA) stops most stolen-password attacks.
- Least privilege: give users only the access they need.
- IDS detects suspicious activity and alerts. IPS detects it and blocks it.
- Firewalls filter traffic by rules, so rule order matters.

## ACSC Essential Eight (examples)
- Patch applications and operating systems
- Multi-factor authentication
- Restrict administrative privileges
- Regular backups
